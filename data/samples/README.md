# Public human-derived trajectory samples

The nine pilot `tracks.npz` files contain planar object/finger coordinates and timestamps extracted from the user's personally recorded phone videos. They include missing detections outside the selected contact segments. They are human video tracks, **not direct robot demonstrations**.

Calibration JSONs are in `data/calibration/`; original source hashes and selected segments are in `data/manifests/public_replay.json`. Original untrimmed videos remain local under `data/raw/` and are excluded from Git. The samples suffice to reproduce simulation replay, but reproducing image tracking requires those originals or your own recordings. All files use the native display orientation and shared user convention.

```bash
MUJOCO_GL=egl uv run --locked python scripts/run_batch.py \
  --manifest data/manifests/public_replay.json --no-video --output outputs/public_replay
```

Robot action labels are generated by the replay controller in simulation. Approach, height/orientation and withdrawal are scripted; pushing references come from the selected tracked finger motion with a constant contact offset. These source clips were used for development/tuning, so their success rates are not held-out performance.

Twelve additional source tracks, `train_001`–`train_012`, are included. Use `data/manifests/public_training_batch_01.json` to replay them. The failed human source tracks remain valid data, with outcomes preserved. See [the review](../../docs/training-batch-01.md).

## Third new training batch and timeout update

Ten source tracks, `train_023`–`train_032`, are included with `data/manifests/public_training_batch_03.json`. The current default push limit is 10 seconds. Three replays pass all checks; 032 reaches the goal but fails scripted approach validity. Earlier five failed sources remain unsuccessful when rerun at 10 seconds. Total: 32 new source tracks, 20 validated expert candidates. See [the third review](../../docs/training-batch-03.md). Earlier batch counts describe their original 8-second runs; specify `--push-timeout-s 8` to reproduce those historical results.
